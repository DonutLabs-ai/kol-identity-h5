## 0. 本地启动（前端 + 后端）

**前置**：Node 18+（生图脚本用 Node 内置 fetch）、Python 3（静态服务器 + 后处理，macOS 自带）。仓库根目录建 `.env`：
```
OPENROUTER_API_KEY=sk-or-v1-…
```
`.env` 已在 `.gitignore`，不要提交。

**前端（H5 + 卡片壳）** — 纯静态，任何静态服务器都行，从仓库根目录起（`identity/` 会用 `../flashcard/`）：
```bash
cd kol-identity-h5
python3 -m http.server 3021 --bind 127.0.0.1
# 打开 http://127.0.0.1:3021/identity/?kol=chriszhu
```
常用参数：`?intro=0` 跳过开屏 · `?kol=chriszhu` 演示账号 · `?strict=1` 真实表单校验 · `?api=http://host:port` 指定生图后端。

**后端（生图 mock，实现了 BACKEND.md 的两个接口）**：
```bash
cd kol-identity-h5
NODE_USE_ENV_PROXY=1 node tools/cardgen/server.mjs --port 3022
```
- `NODE_USE_ENV_PROXY=1` 让 Node 走系统代理（办公室网络访问 OpenRouter 需要；服务器上按需）。
- 前端在 localhost 默认连 `http://127.0.0.1:3022`；线上要设 `window.DONUT_CARD_API`（或 `?api=`）。
- 缓存在 `tools/cardgen/out/server-cache/`，同一头像+人格只生成一次。预热某个人：`--warm chriszhu:diamond_hands:avatars/chriszhu.png`；直接塞一张已有图：再加 `--warm-from out/restyle/FINAL-chriszhu/restyled.png`。
- 一次生成约 3–4 分钟、$0.40；`--cap 20` 设本次进程的花费上限。

**只跑生图、不跑页面**：
```bash
NODE_USE_ENV_PROXY=1 node tools/cardgen/generate.mjs --avatar tools/cardgen/avatars/chriszhu.png --type diamond_hands   # 第一步 GPT
NODE_USE_ENV_PROXY=1 node tools/cardgen/harness/restyle.mjs --image <上一步的png> --avatar <头像> --type diamond_hands --refs "$(paste -sd, tools/cardgen/style-refs/figma/refs-diamond_hands.txt)" --brand --edge-sparkle   # 第二步 Gemini
```
风格参考图在 `tools/cardgen/style-refs/`（第三方素材，本地、未入库——新机器要从 Figma 重新导，见 `tools/cardgen/README.md`）。

**线上**：push 到 `main` → GitHub Actions 自动发布到 https://donutlabs-ai.github.io/kol-identity-h5/ （只发 `identity/`、`flashcard/`，不发 tools）。

## 1. 生图 pipeline：原理与部署

**目标**：KOL 连 X → 答 6 题 → 得到 12 种交易人格之一 → 卡面上出现"他本人"的画像，风格统一为 Donut 的 glare/流光复古未来风。

**原理（两步，两个模型）**

1. **GPT 出稿**（`openai/gpt-5.4-image-2`，走 OpenRouter 的 chat 接口，不是原生 images 接口）。输入：KOL 头像 + 3 张风格参考图（从 Figma moodboard 的"glare十字流光"组按类型自动选）+ 一张 Donut 品牌流光底图 + 文字提示（保持长相、做该人格的标志动作与道具）。GPT 负责**像本人、动作对、道具对**，但它基本无视参考图的风格。
2. **Gemini 重绘**（`google/gemini-3-pro-image`）。输入：第 1 步的图 + 同样 3 张参考图 + 头像 + 品牌底图，指令"整体按参考图风格重绘，构图/姿势/道具/人脸不变，闪光只在轮廓边缘，道具与人物同一材质"。Gemini 负责**学风格**（它对参考图很敏感），单独用它会乱动作、丢脸，所以只让它做重绘。
3. 前端在卡片上再叠一层 CSS 胶片颗粒和十字闪光，所以存图不用加噪点。

每张卡：约 **$0.40、3–4 分钟**（GPT 2.5–3.5 min + Gemini ~1 min）。正在测 `gpt-5-image-mini` 做第一步（预计快一倍、便宜 5 倍）。前端把等待放在"D0 is reading"页（显示百分比），生成完才进结果页。

**部署（后端要做的）**

- 一个服务，两个接口（细节和字段见 `BACKEND.md` §3）：
  - `POST /v1/identity/card-art {type}` → 缓存命中返回 `done + image_url`，否则 `202 queued + job_id`
  - `GET /v1/identity/card-art/{job_id}` → `queued / running / done / failed`
- 头像**服务端从 X 拿**（`profile_image_url` 去掉 `_normal`），不要信客户端传的地址。
- 缓存键：`sha256(头像) + 人格 + prompt 版本 + 模型`。同一个人同一人格只生成一次。
- 密钥 `OPENROUTER_API_KEY` 只放服务端；**聊天里贴过的那把 key 上线前要换掉**。
- 部署地区：OpenRouter 的图片模型对部分地区返回 403（我们办公室网络就是），服务器放在能用的地区。
- 失败/审核拦截 → 返回该人格的默认卡面（`identity/img/archetypes/NN-*.jpg`），揭晓流程永远不等生图。
- 并发建议先 8，每账号每天最多 5 次，设每日花费上限并告警。
- 提示词在 `tools/cardgen/prompts.md`（Base + 每人格一节），风格参考图的选择逻辑在 `tools/cardgen/harness/pick_refs.py --for-type`，重绘逻辑在 `tools/cardgen/harness/restyle.mjs`，`tools/cardgen/server.mjs` 是可直接照抄的参考实现（带缓存、两步流水线）。
- 参考图目前是第三方作品（本地、未入库）。**上线前请换成我们自己的图**（比如已批准的生成卡面），版权和一致性都更稳。

**前端已经接好的钩子**（`identity/theme.js`）：结果页挂载时 `POST`，每 3 秒轮询，`done` 后淡出旧图换新图并放一次金币特效；卡片下方有"D0 正在绘制你的卡面…/已生成/沿用默认"状态。把 `window.DONUT_CARD_API` 指到你们的域名即可（本地默认 `127.0.0.1:3022`，线上默认关闭）。

## 2. 生产走查清单（给 Sean）

**表单与账号**
- Connect X 现在是**假的**（固定 @seanmoore，或 `?kol=` 的演示账号）。真实 X OAuth 是后端依赖；接上后请检查头像、名字、handle 三处都换成真人的（弹窗、第 1 步资料行、卡片 notch 和标题）。
- 第 1 步的邮箱、钱包为空时**测试模式会直接放行**（填演示值）。上线用 `?strict=1` 检查真实校验：无效邮箱、未连钱包要拦住；错误提示要在字段下出现。
- 钱包连接也是 mock（Phantom/Solana 示例）。接真钱包后走查：选钱包 → 网络 → 地址确认 → 返回第 1 步显示"已连接"。
- 第 2 步 6 题不答完，测试模式会自动补默认答案；`?strict=1` 下应提示"请完成全部六个问题"并滚到第一题。
- 中英切换（右上 `.lang`）：所有文案、卡片正反面、人格描述、绿旗/红旗都要跟着换。

**体验**
- 开屏动画每次加载都放，`?intro=0` 跳过；手机上 logo + 标题在卡环中央。
- 分析页 8 秒：卡片壳、星盘、"D0 is reading…"；点右上 × 能回到问卷。
- 结果页一屏内应看到：卡片、"Your trading personality is + 人格名"、一句"最可能说的话"、描述、Share/Save/Follow 一行三个按钮。手机上卡片会自动缩小以塞进首屏。
- 卡片：点卡片翻面（已去掉 Flip 按钮）；正面 3 行文案 + 十字闪光 + 拉丝金属；背面雷达图 + 3 个标签 + 描述。
- 生图等待（2026-09-30 晚改）：**结果页在卡面生成完之前不会出现**。答完题后"D0 is reading"页面就是等待页，显示百分比，按真实进度走（不再固定 8 秒）；生成完自动揭晓并带金币特效。后端失败/超时 → 直接揭晓默认卡面，不能卡住用户。
- 下方"Other trader types"横向自动滚动，触摸可拖，松手 2.5 秒后继续。
- Share 打开 X 发帖（带文案和链接）；Save 下载卡片图（要用生成后的卡面）；Follow 到 @DonutAI。
- 分享出去的链接/OG 图是否用生成后的卡面——这是**待定项**，见 `BACKEND.md` §10。

**已知未完成**

- 生图速度约 3–4 分钟；如需更快可换 `gpt-5-image-mini` 或对 VIP 名单预生成。
